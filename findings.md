# Descobertas e Restrições

- O projeto atual utiliza React com Vite, TypeScript, Tailwind CSS, shadcn/ui (Radix), Lucide Icons e Recharts.
- A aplicação necessita de um front-end robusto e moderno (estilo premium) antes da estruturação final do backend.
- Uma das fontes de dados futuras será o Google Sheets, exigindo integração e automação (via webhooks ou cron jobs futuramente).
